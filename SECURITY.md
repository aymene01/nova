# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.4.x   | ✅        |
| < 0.4   | ❌        |

## Reporting a Vulnerability

This is an educational project for learning Rust and simulation systems.

For any security concerns:

1. Open an issue on GitHub
2. Contact the maintainers directly

## Security Considerations

Nova is a simulation system that:

- Runs locally on your machine
- Does not connect to external networks
- Does not handle sensitive data
- Uses standard Rust memory safety guarantees

No known security vulnerabilities at this time.
